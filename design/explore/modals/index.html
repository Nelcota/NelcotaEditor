Modais em passos, com sidebar

Exemplo principal: Novo vídeo, no passo 2. Embaixo de cada direção, o mesmo sistema num modal curto (Excluir vídeo) e no celular. Para quem vai usar: criador de conteúdo, sem paciência para formulário. Cada passo pergunta uma coisa só, tudo já vem preenchido e dá para voltar em qualquer passo pela sidebar.

A

Trilha

Passos numerados ligados por uma linha. Cada passo mostra o título e uma dica curta. Escolhas em cartões grandes. O mais familiar dos três.

B

Resumo vivo

A sidebar é o resumo: cada passo mostra o que já foi escolhido e um clique volta nele. Não precisa de passo de revisão no fim.

C

Com o Nel

Passos na sidebar e o mascote explicando o passo atual num balão, em uma frase. O mais amigável para quem chega agora.
